# SmartRecipe

## An Offline Ingredient-Based Recipe Recommendation System

------------------------------------------------------------------------

# 1. 项目概述

## 1.1 项目定位

SmartRecipe 是一个基于本地菜谱知识库的离线智能菜谱推荐系统。

用户输入或选择当前拥有的食材，系统通过本地菜谱数据库和食材匹配算法，自动推荐适合制作的菜谱，并展示：

-   菜谱名称
-   食材列表
-   食材匹配情况
-   缺少食材提示
-   烹饪步骤
-   制作时间
-   菜谱分类

系统完全离线运行，不依赖互联网服务，不调用第三方 AI API。

# 5. 系统模块设计

## 5.1 用户交互模块

功能：

-   点击选择食材
-   搜索食材
-   手动输入食材

示例：

已有食材：

-   鸡蛋
-   番茄
-   青椒

点击生成菜谱。

------------------------------------------------------------------------

## 5.2 菜谱数据库模块

数据来源：

HowToCook 开源菜谱。

数据库字段：

  字段               说明
  ------------------ ----------
  id                 菜谱编号
  name               菜名
  ingredients        全部食材
  main_ingredients   主要食材
  steps              制作步骤
  category           分类
  time               制作时间
  difficulty         难度

------------------------------------------------------------------------

## 5.3 食材匹配模块

基础算法：

匹配分数 = 用户拥有食材数量 / 菜谱总食材数量

优化：

主料权重 = 3

调料权重 = 1

综合考虑不同食材的重要程度。

------------------------------------------------------------------------

## 5.4 推荐排序模块

评分规则：

-   Score \> 80%：强推荐
-   50%-80%：推荐
-   \<50%：低匹配

展示：

-   推荐菜谱
-   匹配度
-   已有材料
-   缺少材料

------------------------------------------------------------------------

## 5.5 菜谱展示模块

展示：

-   菜名
-   制作时间
-   难度
-   所需材料
-   制作步骤

------------------------------------------------------------------------

# 10. 项目总结

SmartRecipe 是一个离线运行的基于食材的菜谱推荐系统。

系统结合开源菜谱数据和自主设计的食材匹配算法，根据用户已有食材推荐适合制作的菜品。

最终实现：

-   完全离线运行
-   本地数据管理
-   智能食材匹配
-   菜谱推荐
-   制作流程展示
